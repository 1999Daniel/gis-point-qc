# 人工模拟样例

本目录全部点位为程序人工构造，仅用于验证规则和演示操作。坐标不是外业成果，也不对应名称所述的真实设施；没有引用真实 POI、客户、学校或学生资料。样例本身没有实际坐标参考系；测试时选择 WGS 84 仅验证“已声明”的软件流程，不代表样例空间基准经测量确认。

| 文件 | 内容 | 人工预期 |
| --- | --- | --- |
| template.csv / template.xlsx | 仅包含五个固定表头的空白模板 | 供用户另存后填写；无真实记录 |
| normal.csv / normal.xlsx | 相同的 12 条模拟正常记录 | 0 个字段问题；未声明坐标系仍须待核实 |
| issues.csv / issues.xlsx | 相同的 12 条模拟记录，含故意设置的问题 | 11 个问题：10 个错误、1 个提示，涉及 10 条记录 |
| expected.json | 独立手工指定的问题行、字段、规则、级别 | 不从程序实际结果反推 |

CSV 为 UTF-8 BOM 编码；XLSX 仅有“模拟点位”一个工作表。编号均为文本，保留前导零。行号从包含表头的第 1 行开始。

问题样例第 9 行的经纬度为 `(23, 113)`：纬度越界产生错误；交换后落入合法数值范围另给提示。软件不会自动交换，用户须依据数据来源核实。第 8 行 `(113, -91)` 交换后仍不合法，因此只报纬度越界。

在项目根目录运行 `.venv\Scripts\python.exe scripts\build_samples.py` 可重建四个模拟文件和两个空白模板；加 `--template-only` 时只生成模板。该命令仅重写这些样例和模板，不修改 `expected.json` 或用户数据。
