# GIS 点位质检工具

面向测绘、AI 数据处理、GIS 数据服务团队的点位表交付前质检工具：导入单张 CSV / XLSX 点位表，检查固定字段、编号、类别与经纬度，生成可下载的 HTML 报告和 CSV 问题清单。教学实践可作为附带应用。当前为本地最小原型，实际验证范围见验收记录；不会修改上传原件，不执行坐标转换，也不能证明点位的真实位置精度。

## 启动

1. 在 Windows 上安装 Python 3.12，并确保可从命令行启动。项目依赖版本见 `requirements.txt`。
2. 首次使用双击 `install.cmd` 安装本项目的隔离环境；安装依赖时需要联网。
3. 双击 `start.cmd`，按终端提示打开本地页面。保持窗口开启；完成后按 `Ctrl+C` 停止服务。
4. 如需手动运行：`.venv\Scripts\python.exe app.py --no-browser --port 8765`，然后打开 `http://127.0.0.1:8765`。

如果端口被占用，手动启动时改用其他空闲端口。此版本用于本机操作，不应直接作为面向公网的上传服务部署。安装结束不等于功能验收通过，实际检查记录见 `docs/acceptance.md` 及运行后生成的 `verification/verification.json`。

## 输入约定

首行必须包含以下五个固定表头。可下载页面提供的空白模板，或从 `samples/template.csv` / `samples/template.xlsx` 另存一份填写。编号建议在录入前设为文本，确保 `0001` 不被表格软件转换成 `1`；CSV 在表格软件中打开时也应按文本列导入编号。

| 字段 | 约定 | 示例（人工模拟） |
| --- | --- | --- |
| 编号 | 非空文本，表内唯一 | `0001` |
| 名称 | 非空 | 模拟点位01 |
| 类别 | 默认允许：学校、医疗、交通、文体、公共服务；可在界面设置本次允许的类别 | 学校 |
| 经度 | 十进制度数值，范围 `[-180, 180]` | `113.100001` |
| 纬度 | 十进制度数值，范围 `[-90, 90]` | `23.100001` |

- CSV 推荐 UTF-8 编码（支持 BOM），兼容 GB18030 并在报告记录读取编码；XLSX 仅支持单工作表。旧版 `.xls`、多表工作簿和缺少表头的文件不支持。
- 不支持投影平面坐标（如米）、度分秒字符串、自动识别坐标系或转换坐标系。须按真实来源声明坐标参考系；不清楚时选“未声明”，结果保留待核实提醒。
- 全空白行忽略并计数。部分字段为空的记录仍参与检查；具体优先级见 [规则说明](docs/rules.md)。
- 表内没有问题仅说明已执行的规则通过，不能据此认定分类真实、坐标系正确或满足测绘精度要求。

## 最短演示流程

1. 加载 `samples/normal.csv` 或 `normal.xlsx`；它们各含 12 条人工模拟记录。未声明坐标系时，字段问题为 0，但仍需核实坐标系。
2. 加载 `samples/issues.csv` 或 `issues.xlsx`，应得到 11 个问题（10 个错误、1 个提示），涉及 10 条记录。
3. 查看源表行号、编号、字段、规则、原值与修改建议，下载 HTML 报告和 CSV 问题清单。
4. 在原表副本中修正问题，再上传复查。工具不会自动替你修复或覆盖原表。

所有内置样例均为人工构造，不是实测数据。`samples/expected.json` 是预先人工确定的验收答案；“疑似经纬度反置”提示不构成自动纠正依据。

## 验证与限制

在项目根目录运行 `.venv\Scripts\python.exe -m unittest discover -s tests -v` 执行测试。测试包括人工样例逐项比对、前导零、空值与非法坐标、文件拒绝、报告转义与导出安全等；实际运行结果须查阅当前验收记录，不以这段说明代替验证。运行 `scripts/verify.py` 后，自动验证结果位于 `verification/verification.json`，测试日志位于 `verification/test-log.txt`；浏览器验收另记为 `verification/browser-verification.json`。这些本机证据不进入公开源码包。

本版优先解决表格级基础质量问题，不包含空间叠加、辖区边界、重复点距离、影像识别、外业实测、坐标转换和批量业务系统回写。空间准确性须结合可靠参照数据、对应空间基准和业务允许误差另行验收。

公开部分包含通用质检代码、规则、模拟样例和使用文档。客户原始数据、学生数据、账号密钥、实际项目资料以及约定的专用业务配置不进入公开仓库。本次为首版源码预览，正式项目许可证仍待确认；公开可见不等于授予 MIT 或其他开源许可。

可商业使用的方向已确认；具体许可文本、发布范围与服务约定以后续正式文件为准。定制服务可围绕字段适配、业务类别、规则扩展、私有数据处理及报告交付制定明确验收范围，不承诺当前原型尚未具备的能力。
