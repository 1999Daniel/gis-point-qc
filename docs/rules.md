# 首版质检规则与解释边界

规则适用于首行固定表头 `编号、名称、类别、经度、纬度` 的 CSV / 单工作表 XLSX。行号按源表物理行编号，表头为第 1 行；全空白数据行跳过但单独计数。一个记录可以有多个问题，因此“问题数”和“受影响记录数”不同。

| 代码 | 级别 | 判定与处理 |
| --- | --- | --- |
| REQUIRED | error | 任一必需字段为空或仅空白字符。空坐标仅报缺失，不重复报数字错误。 |
| DUPLICATE_ID | error | 非空编号重复，标出全部重复成员，不能只标第二条。编号作为文本比较，保留前导零。 |
| TYPE_TEXT | error | 编号、名称或类别不是文本，或 XLSX 单元格为错误类型（如 #REF!）。数字格式显示成 `0001` 不代表真实存储为文本，不能据此恢复已经丢失的前导零。 |
| NUMBER | error | 经度或纬度无法解析为有限数值；`NaN`、正负无穷均不接受。 |
| RANGE | error | 经度不在 `[-180, 180]` 或纬度不在 `[-90, 90]`；边界值允许。 |
| CATEGORY | error | 非空类别不在本次配置的允许列表中；默认学校、医疗、交通、文体、公共服务。 |
| FORMULA | error | 必需字段中存在公式，不求值、不执行。该单元格只报公式问题，不追加类别或数值问题。 |
| COORD_SWAP | warning | 两坐标均为有限数值，原顺序越界，但互换后均落入经纬度合法范围。仅提示人工核实，不自动交换。 |

公式识别与报告安全是不同环节：输入中需要核实的公式作为问题报告；CSV 问题清单会对可能被表格软件当作公式执行的文本加安全前缀，HTML 报告对用户输入进行转义。导出显示的安全前缀不应写回原始业务数据。

## 坐标参考系与结论

经纬度合法范围只是数值检查。WGS 84 与 CGCS2000 的数值都可能合法，表格无法据此自动辨别。GCJ-02、BD-09 等位置数据也不能仅凭名称改标成 WGS 84。

未声明坐标系时，即使没有字段错误，也必须保留“待核实”结论；选择坐标系仅表示操作者的声明，不是软件已检测或完成了转换。坐标点可能位于错误城市、错误设施或不同采集时相，首版均不能独立核实。

`(经度=23, 纬度=113)` 会触发纬度越界和反置提示；`(113, -91)` 交换后经度 `-91` 合法，但纬度 `113` 仍越界，不给反置提示。如果两个方向都在合法范围内，首版不猜测反置。

## 输入与输出边界

- 支持 UTF-8 CSV（含 BOM），兼容 GB18030 并记录编码；支持单工作表 XLSX。不支持 XLS、宏工作簿、多工作表以及度分秒或平面坐标。
- 单文件上限 5 MiB，非空数据最多 10000 行；XLSX 解压后不超过 20 MiB、存储行最多 50000（包含格式空行）。
- 缺表头、重复表头、损坏文件等属于输入错误，应先修复文件结构，不生成貌似“通过”的质检结果。
- HTML 报告和 CSV 清单报告发现的问题、建议和范围说明；不生成自动修正后的原表。
- “通过”仅适用于本版规则；不能替代数据来源核查、外业核实、坐标转换验证、空间质量评价或正式测绘验收。

允许类别为当次检查参数，不是全局行业分类标准；换课程、换项目或换业务时应按真实要求重新确认。
